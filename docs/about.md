# About APK Sentinel

APK Sentinel is a bounded static-analysis product for agents and systems that need evidence about Android packages before deciding whether to escalate a sample for deeper review.

It is designed for mobile security, app-review, fraud, trust-and-safety, endpoint, and compliance workflows. The core result is deterministic JSON containing package metadata, permissions, components, signing metadata, bounded URL/domain evidence, suspicious static indicators, evidence-backed findings, and a rule-based risk score.

APK Sentinel does not install or execute APKs, fetch extracted URLs, or claim to prove that a package is safe or malicious.
