Failed or uncertain analysis

For payment or analysis problems, contact admin@willowbirdie.com. This address is monitored for the beta; no response-time SLA is promised. Provide the job ID and public transaction hash, if available. Do not send APKs, signed payment headers, result tokens, credentials or private keys.

Do not pay again or create a second authorization after a timeout or ambiguous failure. Poll an existing result when possible, then ask support to reconcile it. An abandoned job is a terminal failure, not a successful report. Refunds and no-charge retries are not automatic; verified cases require operator review and an explicitly approved remedy. This beta does not establish a guaranteed retention period or data-residency SLA; see security and data handling.
